# Umwelttechnik – Fragenkatalog zum Lernen

Interaktive Lernplattform zum **Fragenkatalog der Vorlesung „Umwelttechnik" (BIS-Maschinenbau, WS 2014/15)**.
Alle Prüfungsfragen sind 1:1 aus dem Katalog übernommen – die Antworten erscheinen **in Blau**, sobald man auf eine Frage tippt.

## Funktionen

- **Frage antippen** → Antwort in Blau aufdecken
- **Abhaken**, was sitzt – der Lernstand wird lokal im Browser gespeichert (`localStorage`), nichts verlässt dein Gerät
- **Fortschrittsanzeige** gesamt und pro Themenbereich
- **Suche** über alle Fragen und Antworten (Tastenkürzel `/`)
- **Themen-Filter** über die Chips oben
- **Prüfungsmodus** (alle Antworten zu), „Alle Antworten" / „Alle zu", „Gelernte ausblenden"
- **Responsive** (Handy/Tablet/Desktop) und **druckbar** (alle Antworten werden beim Drucken aufgeklappt)

107 Fragen aus 16 Themenbereichen: Kläranlage, Abwasser, Altlastensanierung, Abfallvermeidung, Wiederverwendung & Recycling, E-Schrott/Batterien, Altautos, energetische Verwertung, Deponierung, MBA, biologische & thermische Abfallbehandlung, gefährliche Abfälle, Luftschadstoffe, Abgasreinigung, rechtliche Grundlagen.

## Auf GitHub Pages veröffentlichen

1. Neues Repository auf GitHub anlegen (z. B. `umwelttechnik-lernen`).
2. `index.html` (und optional diese `README.md`) hochladen.
3. Im Repo: **Settings → Pages → Build and deployment → Source: „Deploy from a branch"**, Branch `main`, Ordner `/ (root)` wählen, speichern.
4. Nach ein bis zwei Minuten ist die Seite unter `https://<dein-benutzername>.github.io/umwelttechnik-lernen/` erreichbar.

Alternativ lokal: Einfach die Datei `index.html` doppelklicken – sie läuft komplett offline, ohne Server.

## Hinweis zu Skizzen-Fragen

Einige Katalog-Fragen verlangen nur eine Zeichnung/einen Graphen (z. B. „Skizzieren Sie den Aufbau einer Kläranlage"). Diese sind **amberfarben** markiert und verweisen auf die passende Foliendatei, da im Katalog dafür keine ausformulierte Textantwort steht.
